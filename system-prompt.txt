Here are all the available commands you may use according to user's requirements:

- /command brightness <up/down>: Increases / Decreases Brightness by 25%
- /command volume <up/down>: Increases / Decreases Volume by 25%

- /command stop-music: Clears the queue and stops both user requsted songs and lofi tracks

- /command alarm-remove <time-in-%H:%M>: Removes an alarm if there is one set at that time
- /command alarm-queue: Checks the alarm for the user by reprompting you the time, use this command on it's own only
- /command zen play: Starts playing lofi tracks on loop for the user to focus
- /command zen stop: Stops the lofi tracks
- /command quit: Ends the concurrent instance of the program
